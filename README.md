# フォーム — パーソナルトレーニング記録

Stage 1として、iPhoneとデスクトップに対応したアプリの土台を用意しました。ダッシュボード、トレーニング、筋肉マップ、成長記録、種目一覧の画面があります。筋肉マップでは前面・背面を切り替えて筋肉を選べます。トレーニング記録、グラフ、種目データは次の段階で追加します。

## iPhoneで開く方法

見た目だけを確認する場合は、パソコンのSafariで `index.html` を開きます。iPhoneのホーム画面に追加してPWAとして使うには、HTTPS対応のWebサイトに公開してください。ファイルを直接開いた場合、Service Workerやホーム画面アプリの機能は動きません。

初めての方にはGitHub Pagesでの公開が手軽です。

1. GitHubにサインインし、このプロジェクト用の新しいリポジトリを作ります。
2. このフォルダ内のファイルとフォルダをリポジトリに追加します。
3. リポジトリの **Settings → Pages** を開き、公開方法で **Deploy from a branch** を選びます。ブランチは `main`、フォルダは `/ (root)` にして保存します。
4. GitHub Pagesに公開先のURLが表示されたら、そのHTTPSのURLをiPhoneのSafariで開きます。
5. Safariの **共有** ボタンをタップし、メニューをスクロールして **ホーム画面に追加** を選びます。名前を確認して **追加** をタップします。
6. ホーム画面にできた「フォーム」のアイコンを開きます。一度オンラインで開くと、アプリの基本画面をオフラインでも表示できます。

「ホーム画面に追加」が見当たらない場合は、アプリ内ブラウザではなくSafariで開いていること、URLがHTTPSで始まっていることを確認してください。

## iPhone Safariでの保存について

このアプリは端末内に `form-training` というIndexedDBデータベースを作り、トレーニングと設定用の保存領域を準備します。Stage 1ではまだトレーニング記録を保存しません。今後追加する記録はこの端末のブラウザ内に保存し、アカウントやクラウド同期は使いません。iOSは空き容量が少ない場合にWebサイトのデータを削除することがあります。SafariのWebサイトデータを消去したり、アプリを削除したりすると、端末内の記録も失われる可能性があります。記録機能を追加した後は、別途バックアップを取ってください。プライベートブラウズは継続保存には適しません。

Service Workerは、初回のオンライン表示後にアプリの基本ファイルを保存し、次回以降のオフライン表示に使います。初回表示や更新にはインターネット接続が必要です。iPhoneのSafariでは自動インストール案内は出ないため、**共有 → ホーム画面に追加** を使います。
